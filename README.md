# 🚘 Aski Project

University project (Web & Mobile Programming, 2023) for a car-sharing platform with Android client, backend integration, and SQL schema.

## 👥 Authors

- [Slenderman0039](https://github.com/Slenderman0039)
- [ashenclock](https://github.com/ashenclock)

## 🧩 Project Scope

The app is designed to support:

- user registration and profile management
- car search and booking workflows
- map/location integration
- simulated payment flows for educational purposes

## 🛠️ Tech

- Kotlin / Android SDK
- Gradle
- Firebase (selected modules)
- Retrofit / Gson / Moshi
- Google Maps / Location APIs
